# Vouches layout drafts

Five ways to show more customer vouches at once on the homepage. Each file is the full
current homepage with only the "What customers say" section changed — everything else
(header, hero, CTAs, trust note, shipping/insurance, footer, dialogs) is untouched.

Not linked from anywhere on the live site and not deployed — open the files directly to
preview.

- `1-grid-paginated.html` — 3 (mobile) to 6 (desktop) column grid, 12 vouches shown up
  front with a "Show more" button for the rest.
- `2-dense-strip.html` — Same horizontal swipe/scroll strip as the live site, just with
  smaller cards so more fit on screen at once without scrolling.
- `3-square-grid.html` — Like draft 1 but cropped to square thumbnails, so even more fit
  per row (4 mobile / 8 desktop), 16 shown up front.
- `4-two-row-strip.html` — Horizontal scroll strip arranged in two stacked rows, doubling
  how many are visible per scroll position.
- `5-full-wall.html` — All 51 vouches shown at once in a dense grid, no scrolling strip
  and no "show more" — just scroll the page.

All five keep the same tap-to-open full-screen viewer, swipe/keyboard navigation, and the
"open in your browser" leave-site warning on outbound Telegram/iMessage links.
